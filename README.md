# celso.io

This is a [Hugo](https://gohugo.io/) site running on [Cloudflare Pages](https://developers.cloudflare.com/pages/framework-guides/deploy-a-hugo-site/) that deploys to https://celso.io/

## Development Commands

- `hugo serve` - Start local development server

## Architecture

- **Blog posts**: `content/posts` contains the markdown blog posts
- **Images and assets**: `assets` contains image files and other assets

## Key Technical Details

- **Markdown**: All blog posts are in English and markdown language

## Configuration

- Hugo configuration in `hugo.toml`

## AI Guidelines

I like writing and I write my blog posts, not AI. I use AI to proof read what I write because I'm not native English.

I may also use AI to assist me in coding small demos or scripts that this blog uses or mentions, for example [static/telematico/](static/telematico/).

## Writing style

I'm a nerd. I've been around the Internet since the 90s, amateur radio, BBSes and modems and 8-bit home computers before that.

More about me [here](content/about.md).

My writing voice is conversational, warm, playful and personal, blending hands-on technical depth with autobiographical storytelling in a way that feels like a long, relaxed chat with a knowledgeable friend. I write in first person and frequently address the reader directly ("Many of you might be familiar...", "If you're the rabbit hole type...").

My prose is generous with context: I anticipate what a curious but non-expert reader will not know, explain it patiently with analogies, and link liberally to outside sources so readers can go deeper without I having to over-explain. The pacing is unhurried and chronological, with structural signposting through clear section headings and italicized asides ("Side note:") for tangents I can't resist.

I favor short, punchy sentences for emotional beats, interleaved with longer, technically dense passages.

There's consistent self-deprecating humor and emotional honesty about frustration and luck, and I'm quick to credit and thank others rather than center myself as the sole hero.

## Coding style

I like things simple, readable, very short comments, one or two lines maximum, but if just one, concise code.

Formatting is spaces for white-space, not tabs, 2 chars.
